Tired of having to manually code the rotation and positions of your sprites when doing live animation in tModLoader? Worry not!!

Terranimator lets you animate your Terraria mod sprites using keyframes, with gizmos that make positioning and rotating your sprites infinitely easier than you'd think!

Once you're done animating, export your work as a spritesheet ready to use in your mod, or generate code you can drop straight into your tModLoader project. No more manually tweaking every rotation and position!

I'm gonna be honest, I made this because I was mad at the fact I was genuinely horrible at animating 2d sprites the way it's usually done, so I did it in a way that would benefit me. Maybe it can benefit you!
